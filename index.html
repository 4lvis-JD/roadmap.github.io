Etapa 1: Fundamentos de la Web

Objetivo: Entender qué es la web, cómo funcionan los navegadores y los servidores.

  • Cómo funciona la web
  • Internet y WWW

Tareas prácticas:

  • Crear tu primer pequeño archivo HTML y abrirlo en el navegador.
  • Inspeccionar páginas web conocidas usando las herramientas de desarrollador (DevTools).

Etapa 2: HTML Básico y Semántico

Objetivo: Crear estructuras web sólidas y accesibles.

  • Introducción a HTML
  • Estructura de una página web HTML
  • HTML Semántico

Tareas prácticas:

  • Crear una página básica con: Encabezados, Párrafos, Listas, Imágenes, Hipervínculos.
  • Usar etiquetas semánticas como <section>, <article>, <nav>, etc.
¿Qué verás aquí?
Aprenderás la estructura esencial del HTML y cómo organizar el contenido con significado usando etiquetas semánticas.

Etapa 3: CSS Básico (Estilizando la Web)

Objetivo: Hacer páginas atractivas y bien estructuradas.

  • Introducción a CSS
  • Sintaxis de CSS
  • Selectores de CSS

Tareas prácticas:

  • Crear hojas de estilo externas.
  • Aplicar colores, fuentes, márgenes, padding.
  • Diseñar un layout básico usando flexbox.
¿Qué verás aquí?
Estilos visuales, jerarquía, clases, selectores y disposición de elementos en pantalla.

Etapa 4: JavaScript Fundamental

Objetivo: Entender la lógica, interacción y comportamiento en la web.

  • Primeros pasos con JavaScript
  • Funciones
  • Eventos en el DOM
  • Manipulación del DOM

Tareas prácticas:

  • Mostrar alertas, manipular textos dinámicamente.
  • Agregar interactividad (botones que cambian texto, ocultan elementos, etc.).

Etapa 5: Responsive Design

Objetivo: Que tus páginas se vean bien en dispositivos móviles.

  • Responsive Design Basics
  • Media Queries

Tareas prácticas:

  • Adaptar una página para que se vea bien en móvil y escritorio.

Etapa 6: Accesibilidad Web (A11y)

Objetivo: Hacer sitios inclusivos para personas con discapacidades.

  • Accesibilidad web
  • Accesibilidad en HTML

Tareas prácticas:

  • Usar etiquetas correctas (alt en imágenes, roles, navegación por teclado).

Etapa 7: Git y GitHub

Objetivo: Controlar versiones de tus proyectos.

  • Git básico en MDN

Tareas prácticas:

  • Crear un repositorio Git.
  • Subir tus proyectos a GitHub.

Etapa 8: Construcción de Portafolio

Objetivo: Mostrar tus habilidades al mundo.

  • Una landing page de producto.
  • Un pequeño blog personal.
  • Una galería interactiva de imágenes.
  • Un formulario funcional con validación básica en JS.
